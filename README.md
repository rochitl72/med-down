# Aravind Clinical EMR Design

This project contains the base UI/UX skeleton for the Aravind Clinical EMR Design system.

## Project Structure

```
.
├── UI/                    # UI/UX skeleton and base components
│   ├── src/              # React application source code
│   ├── package.json      # Dependencies and scripts
│   ├── vite.config.ts   # Vite build configuration
│   └── README.md        # UI skeleton documentation
├── guidelines/          # Project guidelines and design system rules
├── medical_knowledge.json # Medical knowledge base (to be added)
├── .env                  # Environment variables (to be added)
└── README.md           # This file
```

## Getting Started

The UI skeleton is located in the `UI/` folder. To work with it:

1. Navigate to the UI folder:
   ```bash
   cd UI
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
